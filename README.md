# VACCINATION-DISTRIBUTION
This project focuses on analyzing global vaccination distribution data to understand patterns and disparities in vaccination rates across different countries and regions.

The goal is to explore how vaccination coverage varies worldwide and to identify trends using data analysis and visualization techniques.

The project includes data preprocessing, exploratory data analysis (EDA), and visualization of vaccination distribution across populations.

Tech stack: Python, Pandas, NumPy, Matplotlib, Seaborn

Key steps:

Data cleaning and preprocessing
Exploratory data analysis (EDA)
Distribution analysis of vaccination rates
Comparison across countries/regions
Data visualization and insight extraction
